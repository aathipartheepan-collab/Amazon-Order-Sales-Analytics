# Amazon Order & Sales Analytics Dashboard

## Project Overview
This project presents an interactive Amazon order and sales analytics dashboard built with Microsoft Power BI. It is designed to explore sales performance, order trends, product performance, customer behavior, reviews, discounts, and inventory-related information.

## Project Objectives
- Analyze order and sales performance.
- Explore product and category performance.
- Understand customer and purchasing trends.
- Review customer feedback and ratings.
- Examine discounts and inventory-related information.
- Present key metrics through interactive visuals.

## Tools & Technologies
- **Microsoft Power BI** — Dashboard development and data visualization
- **Power Query** — Data preparation and transformation, if used in the project
- **SQL / Python / Pandas** — Include these only if they were used in your project workflow

## Dashboard Features
- KPI cards for important business metrics
- Interactive charts and visualizations
- Filters and slicers for exploring the data
- Sales, order, product, and category analysis
- Customer behavior and review analysis
- Discount and inventory analysis

## Project File
Open `amazon(1).pbix` using Microsoft Power BI Desktop to explore the report.

## How to Use
1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open `amazon(1).pbix`.
4. If prompted, update data-source paths or credentials.
5. Refresh the data if the original data sources are available.
6. Explore the report using its visuals, slicers, and filters.
