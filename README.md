# Amazon Order & Sales Analytics Dashboard

## Project Overview
This project is an interactive Amazon analytics dashboard developed in Microsoft Power BI. It brings together sales and order KPIs with product, review, location, and customer-related views to support exploration of business performance.

## Dashboard Pages

### 1. Overview
- Total Sales KPI
- Total Orders KPI
- Amazon-themed report navigation and visual design

### 2. Reviews, Products & Location Analysis
- Total Count of Rating KPI
- Average Rating KPI
- State-based map visuals
- Category-based analysis
- Waterfall chart and clustered column chart
- State and category slicers for interactive filtering

### 3. Customer Analysis
- Average Sales KPI
- Gender-based donut and pie charts
- Gender comparison visual
- Prime Member slicer for customer segmentation

## Tools & Technologies
- **Microsoft Power BI** — Dashboard development and data visualization
- **Power Query** — Include as a project tool if used for data preparation

## Key Features
- Sales and order KPI cards
- Review rating metrics
- Geographic analysis by state
- Product category analysis
- Customer demographic views
- Prime membership filtering
- Interactive slicers and visualizations

## How to Open the Project
1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open `amazon(2).pbix` in Power BI Desktop.
4. If Power BI prompts for data sources, update the paths or credentials as needed.
5. Refresh the data if the source files are available.
6. Use the slicers and report visuals to explore the dashboard.
